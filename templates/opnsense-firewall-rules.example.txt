# --- Interface: MGMT_LAN (VLAN 10) ---
# 1. PASS  src MGMT_LAN net -> dst any, ports any
#        Admin segment may initiate anywhere (incl. hypervisor + firewall mgmt).

# --- Interface: SERVERS (VLAN 20) ---
# 1. BLOCK src SERVERS net -> dst MGMT_LAN net, log = on
#        No server-initiated traffic into the admin segment.
# 2. PASS  src SERVERS net -> dst any (WAN), ports 80,443
#        Updates only.
# 3. PASS  src SERVERS net -> dst 192.168.20.1, port 53
#        OPNsense fallback DNS.
# 4. (default) BLOCK everything else, log = on

# --- Interface: IOT_GUEST (VLAN 30) ---

#        DNS forwarder + gateway services only.
# 3. PASS  src IOT_GUEST net -> dst any (WAN), ports 80,443
#        Guest internet.
